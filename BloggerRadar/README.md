# 博主雷达（BloggerRadar）

自用安卓工具：**打开小红书时，自动把 Excel 名单里的博主昵称高亮出来**，不用再人工对照表格找。

原理：安卓官方无障碍服务（AccessibilityService）读取小红书界面文字 → 与本地名单模糊匹配 → 全屏透明悬浮层画绿色高亮框 + 名字角标。
- 不需要 Root
- 不需要悬浮窗权限（用的是无障碍自带的 overlay 类型）
- 不联网，名单只存在手机本地

## 功能

| 功能 | 说明 |
|------|------|
| 导入 Excel 名单 | 支持 `.xls`（Excel 97-2003）/ `.csv` / `.txt`；**.xlsx 需先另存为 .xls** |
| 模糊匹配 | 自动处理表格里多余空格、全角空格；小红书超长昵称被截断成「xxx…」也能匹配 |
| 实时高亮 | 绿色圆角框 + 「✓ 昵称」角标，滚动/刷新自动重新扫描 |
| 本地开关 | App 内可随时关闭实时高亮，名单随时清空重导 |

## 如何打包 APK（二选一）

### 方式 A：GitHub 云端打包（电脑无需装任何东西，推荐）
1. 注册/登录 GitHub，新建一个仓库（如 `BloggerRadar`）
2. 把本文件夹全部内容上传到仓库（网页端 Add file → Upload files 拖进去即可）
3. 仓库页点 **Actions** → 选 **Build APK** → **Run workflow**，等 3~5 分钟
4. 该次运行页面底部 **Artifacts** 下载 `BloggerRadar-debug-apk`，解压得到 `app-debug.apk`
5. 传到手机安装（微信文件传输助手即可）

### 方式 B：本地 Android Studio
1. 安装 Android Studio → 打开本文件夹
2. 等待 Gradle Sync 完成 → 菜单 Build → Build APK(s)
3. APK 在 `app/build/outputs/apk/debug/`

## 手机上如何使用

1. 安装 APK 并打开「博主雷达」
2. 点 **① 导入 Excel 名单**，选中整理好的 `.xls` 表格（微信里收到的文件 → 用「文件管理器」选择）
3. 点 **② 开启无障碍服务** → 跳到系统设置 → 找到「博主雷达」→ 打开开关 → 允许
   （部分国产 ROM 会提示"该服务可能获取屏幕内容"，属正常，这是本地识别文字用的）
4. 打开小红书，刷到名单里的博主时，昵称会被绿框高亮 ✓

## 注意事项

- 表格建议把昵称整理在一列/一个区域；空行空列自动跳过；重复昵称自动去重
- 小红书改版若导致识别失效，通常只需要微调无障碍扫描逻辑，名单数据不受影响
- 部分手机（小米/华为等）需要在设置里给本 App 加锁/允许自启动，避免无障碍服务被系统杀掉；服务被杀后重新到无障碍设置里开关一次即可
- 本工具仅个人使用，请勿用于批量自动化操作账号等违反平台规则的用途
